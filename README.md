# Portfólio – Jhonathan Domingues

Este repositório contém o código-fonte do meu site pessoal de portfólio, voltado para apresentação de Provas de Conceito (POCs) em Ciência de Dados, Analytics e Engenharia de Dados.

O objetivo principal do site é demonstrar, de forma clara e acessível, soluções práticas para problemas reais de negócio, com foco em comunicação executiva e aplicação técnica.

---

## Objetivo do projeto

Este site foi desenvolvido para:

- Apresentar minhas POCs de forma organizada e profissional  
- Demonstrar capacidade técnica e visão analítica  
- Servir como vitrine do meu trabalho em Data Science  
- Facilitar a compreensão de projetos por públicos técnicos e não técnicos  

---

## Principais funcionalidades

- Página inicial com apresentação pessoal  
- Página de listagem de cases (POCs)  
- Páginas individuais para cada prova de conceito  
- Navegação em modo claro e escuro  
- Conteúdo estruturado via Markdown  
- Layout responsivo e otimizado para leitura  

---

## Tecnologias utilizadas

- Astro  
- Tailwind CSS  
- TypeScript  
- Content Collections (Markdown)  
- GitHub Pages  

---

## Estrutura geral

- `/src/pages` – páginas principais do site  
- `/src/components` – componentes reutilizáveis  
- `/src/content/cases` – conteúdo das POCs em Markdown  
- `/public` – imagens e assets estáticos  

---

## Créditos

Este site foi desenvolvido a partir do template open source **Astro Multipage Portfolio**, criado por **Tomcomtang**.

- Template: Astro Multipage Portfolio  
- Autor: Tomcomtang  
- Página do tema: https://astro.build/themes/details/astro-multipage-portfolio/  
- Repositório original: https://github.com/tomcomtang/astro-multiplepage-portfolio.git  

O template original foi adaptado e personalizado para atender às necessidades específicas deste portfólio, incluindo alterações de layout, estrutura de conteúdo, estilização e integração com POCs em Markdown.
